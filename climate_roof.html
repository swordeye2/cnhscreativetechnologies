📡 DHT11 Single-Wire Communication Protocol 40-Bit Frame

When sensor.measure() runs, RP2040 pulls GP15 LOW for 18ms to signal start. The DHT11 responds with 40-bit Pulse-Width Modulated data (16-bit Humidity, 16-bit Temp, 8-bit Checksum):

Humidity (16-bit): 00110010 00000000
Temp (16-bit): 00011001 00000000
Checksum (8-bit): 01001011

import dht, machine, time
sensor = dht.DHT11(machine.Pin(15)) # Single-wire GP15
in1 = machine.Pin(16, machine.Pin.OUT) # Roof Motor CW
in2 = machine.Pin(17, machine.Pin.OUT) # Roof Motor CCW
fan = machine.Pin(18, machine.Pin.OUT) # Exhaust Fan

while True:
  sensor.measure() # Triggers 40-bit Single-Bus Read
  temp = sensor.temperature() # 25.0°C
  hum = sensor.humidity() # 50.0%

  # Compound Condition: HIGH Temp AND HIGH Humidity
  if temp > 30 and hum > 70:
    in1.value(1); in2.value(0) # Close Roof (Protect)
    fan.value(1) # Turn ON Exhaust Fan
  elif temp > 32:
    in1.value(0); in2.value(1) # Open Roof (Vent Heat)
    fan.value(0) # Fan OFF
  else:
    in1.value(0); in2.value(0) # Motor STOP
    fan.value(0) # Fan OFF

  time.sleep(2)
