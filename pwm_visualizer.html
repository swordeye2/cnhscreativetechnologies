⚡ RP2040 Bidirectional PWM Ports & Multi-Resolution Conversions
Bidirectional Ports: The RP2040 microcontroller contains 8 hardware PWM slices (16 total channels). All 30 GPIO pins are bidirectional—they can output PWM signals to actuators (e.g., ESCs, servos, LEDs) or capture incoming PWM signals from external sensors (e.g., ultrasonic sensors, RC receivers) using high-speed hardware counter clocks.

Bit Resolution Mapping: The RP2040 uses 16-bit registers (0 to 65,535). When communicating with 8-bit hardware devices (0 to 255) or 10-bit ADCs (0 to 1,023), values are converted using bit-shift operations or ratio scaling: 16-Bit: 0 – 65,535 8-Bit: 0 – 255 Bidirectional: Input Capture & Output
Duty Cycle (16-Bit Register Value): 32,768 u16 (50.0%)
Signal Frequency (Hz): 1,000 Hz (Period: 1.00 ms)

🐍 MicroPython Code: Bidirectional PWM & Conversion
from machine import Pin, PWM

# 1. OUTPUT: PWM Generator (16-bit u16)
pwm_out = PWM(Pin(15))
pwm_out.freq(1000)
pwm_out.duty_u16(32768)

# 2. CONVERSION: Scale 8-bit sensor (0-255) to 16-bit
def write_8bit_to_pwm(val_8bit):
  val_16bit = (val_8bit << 8) | val_8bit # Scale 8->16 bit
  pwm_out.duty_u16(val_16bit)

# 3. INPUT: Read incoming PWM signal from pin
def read_8bit_from_pwm16(u16_val):
  return u16_val >> 8 # Shift right 8 bits: 128
