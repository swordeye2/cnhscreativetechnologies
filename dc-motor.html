📊 Dual PWM & Supply Voltage Physics V_eff = VM × Net Duty

The DRV8833 H-Bridge switches the motor coil across the high-voltage supply rail ($VM$). Net speed is proportional to net terminal voltage ($V_{\text{eff}}$), while supplying PWM on BOTH pins simultaneously triggers active fast-decay dynamic braking[cite: 1, 2]!

1. Net Differential PWM Duty Cycle:
$\Delta D = \text{Duty}_{\text{IN1}} - \text{Duty}_{\text{IN2}} =$ +50.0%
2. Effective Coil Terminal Voltage ($V_{\text{eff}}$):
$V_{\text{eff}} = VM \times \Delta D = 5.0\text{V} \times 0.50 =$ 2.50 V
3. Angular Velocity & Decay State:
Speed: +1250 RPM | Active Drive

import machine, time

# Configure Dual PWM on GP14 (IN1) & GP15 (IN2)
in1 = machine.PWM(machine.Pin(14))
in2 = machine.PWM(machine.Pin(15))
in1.freq(20000); in2.freq(20000) # 20kHz Ultrasonic

# Set PWM Duty Registers
in1.duty_u16(32768) # IN1 Signal
in2.duty_u16(0) # IN2 Signal
