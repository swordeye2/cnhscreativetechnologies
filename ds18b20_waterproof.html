📡 Dallas 1-Wire ROM & Scratchpad RAM Addressable

Every DS18B20 contains a unique 64-bit laser-etched ROM code. Multiple waterproof sensors can share the exact same GP22 data wire:

Unique 64-Bit ROM ID (roms[0]):
bytearray(b'\x28\xFF\x64\x1E\x82\x22\x04\x9B')
Family: 0x28 Serial: 48-Bit Unique CRC: 0x9B
Scratchpad Temperature Register (Bytes 0 & 1):
Raw Hex: 0x0190 12-Bit Temp: 25.00°C
🐍 MicroPython 1-Wire Driver Code RP2040 Executing
import machine, onewire, ds18x20, time

# Configure 1-Wire bus on GP22 (4.7kΩ pull-up)
ow = onewire.OneWire(machine.Pin(22))
ds = ds18x20.DS18X20(ow)

# Scan bus for sensor ROM IDs
roms = ds.scan()

while True:
  ds.convert_temp() # Start 12-bit ADC conversion
  time.sleep_ms(750) # Required 750ms conversion delay
  for i in range(len(roms)):
    t = ds.read_temp(roms[i]) # 25.00°C
    print("Sensor:", roms[i], "Temp:", t)
  time.sleep(1)
