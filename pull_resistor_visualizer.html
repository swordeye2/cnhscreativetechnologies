RP2040 Internal Pull-Up vs. Pull-Down Physics Simulator

Visualizing Default Idle Voltages, Active Switch Closures, and Active-LOW / Active-HIGH Logic

⚡ Internal Resistor Voltage Reference Physics
Pull-Down Resistor (Default = 0.0V LOW / `0`): Connects the input pin to Ground via an internal ~50kΩ resistor. When the switch is open, the pin stays tied to 0V. Closing the switch connects direct 3.3V, pulling the pin HIGH (`1`).
Pull-Up Resistor (Default = 3.3V HIGH / `1`): Connects the input pin to 3.3V VCC via ~50kΩ. When the switch is open, the pin reads 3.3V (`1`). Closing the switch shorts the pin to Ground, pulling it LOW (`0`) (Active-LOW logic).

Pin.PULL_DOWN: Idle = 0V (LOW) | Pressed = 3.3V (HIGH) Pin.PULL_UP: Idle = 3.3V (HIGH) | Pressed = 0V (LOW)
