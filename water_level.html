🐍 MicroPython Code Inspector
import machine, time adc_sensor = machine.ADC(machine.Pin(26)) relay_pump = machine.Pin(16, machine.Pin.OUT) buzzer = machine.Pin(17, machine.Pin.OUT) LOW_THRESH = 25.0; FULL_THRESH = 85.0 pump_active = False while True: level = (adc_sensor.read_u16()/65535)*100 if level <= LOW_THRESH and not pump_active: relay_pump.value(1); buzzer.value(1) pump_active = True elif level >= FULL_THRESH and pump_active: relay_pump.value(0) # Pump OFF pump_active = False

🔌 Circuit Schematic Notes

  • Water Level Sensor: VCC → 3.3V, GND → GND, Signal → RP2040 GP26 (ADC0).
  • Relay Module: VCC → 5V, GND → GND, IN → RP2040 GP16.
  • Refill Pump Motor: Wired through Relay NO (Normally Open) contact terminal.
  • Piezo Buzzer: Connected to GP17 to emit a low-water warning beep when refill engages.
