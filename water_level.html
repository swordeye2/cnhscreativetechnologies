🐍 MicroPython Code (RP2040) 
import machine
import time

# Pin Assignments
adc_sensor = machine.ADC(machine.Pin(26)) # Probe ADC0
relay_pump = machine.Pin(16, machine.Pin.OUT) # Refill Pump
buzzer = machine.Pin(17, machine.Pin.OUT) # Alarm

# Threshold Percentages
LOW_THRESHOLD = 25.0  # Turn Pump ON below 25%
FULL_THRESHOLD = 85.0 # Turn Pump OFF above 85%

pump_active = False

def read_water_percentage():
    raw = adc_sensor.read_u16()
    # Map 16-bit ADC (0-65535) to 0.0% - 100.0%
    percent = (raw / 65535.0) * 100.0
    return percent

while True:
    level = read_water_percentage()
    
    # Hysteresis Tank Refill Logic
    if level <= LOW_THRESHOLD and not pump_active:
        relay_pump.value(1) # Start Pump
        buzzer.value(1)     # Alert Pulse
        pump_active = True
        print(f"WATER LOW ({level:.1f}%): Pump ON")
        time.sleep(0.2)
        buzzer.value(0)
        
    elif level >= FULL_THRESHOLD and pump_active:
        relay_pump.value(0) # Stop Pump
        pump_active = False
        print(f"TANK FULL ({level:.1f}%): Pump OFF")
        
    time.sleep(0.5)

🔌 Circuit Schematic Notes

  • Water Level Sensor: VCC → 3.3V, GND → GND, Signal → RP2040 GP26 (ADC0).
  • Relay Module: VCC → 5V, GND → GND, IN → RP2040 GP16.
  • Refill Pump Motor: Wired through Relay NO (Normally Open) contact terminal.
  • Buzzer: GP17 (Active Piezo Buzzer) triggers audio click on refill state changes.
