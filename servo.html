🧮 Live PWM Calculation Breakdown
1. Period from Frequency:
T = 1000 / 50 Hz = 20.0 ms
2. Pulse Width Interpolation (0.5ms - 2.5ms):
Width = 0.5 + (90° / 180°) × (2.5 - 0.5)
Width = 1.50 ms
3. Duty Cycle & 16-Bit Register (duty_u16):
Duty % = 1.50ms / 20.0ms = 7.50%
duty_u16 = int(0.075 × 65535) = 4915
💡 Frequency Effect: Switching to 100Hz doubles the duty cycle fraction (7.5% at 50Hz vs 15.0% at 100Hz) to output the exact same physical pulse width!
